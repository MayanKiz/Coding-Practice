# Contributing

Thanks for helping improve this coding-practice repository!

## How to contribute

1. Fork this repository.
2. Create a branch for your change, such as `add-prime-number-c`.
3. Add or improve a source file in the appropriate language/topic folder.
4. Test the code where possible and use a clear filename.
5. Commit your changes and open a pull request explaining what changed.

## Guidelines

- Prefer source code over compiled binaries. Do not commit generated `.exe`, `.out`, or other build files.
- Use descriptive filenames, such as `prime_number.c` or `reverse_string.py`.
- Keep each beginner exercise focused on one problem.
- Add comments when they help explain the logic.
- Never add private information, credentials, or personal documents.
- Be respectful and constructive in discussions.

Bug fixes, corrections, and new practice problems are welcome.
